# Monitor Saude

> Non-invasive vital signs monitoring using 60GHz mmWave radar technology.

VitalSense is a monitoring system designed to collect and visualize **heart rate and breathing data** without cameras or wearable devices.

The system combines a **60GHz mmWave sensor**, an **ESP32**, **Firebase Realtime Database**, and a **Flutter Web application**.

## ⚙️ How it works

```text
MR60BHA2 Sensor
      ↓
